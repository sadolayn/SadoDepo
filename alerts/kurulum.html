⚙️ Alerts Kurulum

💻 En kolayı bilgisayardan yapmak. Telefondaysan Chrome menüsünden “Masaüstü sitesi”ni aç.

1Kodu kopyala

Aşağıdaki düğme kodun tamamını panoya kopyalar.

2Yeni proje aç

Gmail hesabınla açılır. Editördeki hazır satırları sil, kopyaladığın kodu yapıştır, 💾 Kaydet.

➕ script.google.com’da yeni proje

3setup’ı çalıştır

Üstteki işlev listesinden setup seç → ▶ Çalıştır. İzin penceresinde: İzinleri incele → hesabın → Gelişmiş → Sadolayn Alerts'e git (güvenli değil) → İzin ver. (Kendi yazdığın kod olduğu için bu uyarı normal.)

4Web uygulaması olarak dağıt

Sağ üstte Dağıt → Yeni dağıtım → türü ⚙️ Web uygulaması.
Şu kullanıcı olarak çalıştır: Ben
Erişimi olanlar: Herkes
→ Dağıt

5Adresi Claude’a gönder

…/exec ile biten Web uygulaması URL’sini kopyalayıp sohbete yapıştır. Siteye ekleyince sistem açılır.
