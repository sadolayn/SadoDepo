# Sado Oyunlar

Telefonda oynanabilen basit oyunlar:

- **Batak** (`batak.html`): İhaleli batak, 3 bilgisayar rakibe karşı
- **Bankacılık** (`banka.html`): BCH rotatif kredi, vadeli mevduat ve tüketici kredisi hesaplama
- **Sayı Tahmin** (`tahmin.html`): Tutulan sayıyı bul
